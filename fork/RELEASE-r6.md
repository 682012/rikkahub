## 本轮变化

- 三种可持久切换的真实聊天布局：经典、工作台、专注。头部、输入区、消息卡片、阅读宽度和抽屉一起切换，消息、工具、语音、文件与统计共用原数据链。
- 全局壁纸可沉浸到页面和系统栏；历史会话使用它自己的助手背景，优先于全局壁纸。支持可见度、主题色遮罩、模糊、裁切/完整显示、九宫格焦点和前景面板强度。图片失败回到安全实色/继承背景，文字和系统栏有对比保护。
- 本地相册图片复制到私有目录，随文件备份，写盘完成后再清理旧图；网络图只接受 http/https。保留原有预设、自定义、动态配色、浅深色及 AMOLED 选项。
- 工作区新增主动授权的 Android 宿主命令，App / Shizuku / 已有 su Root 入口分开；按工作区保存目录映射与 Linux 信任。授权留在 noBackup，不随 ZIP/聊天备份迁移，撤销不会重放命令，移除映射不删原目录。
- 完整保留 r5 的实时单对话统计、缓存异常显示和真实流式计时，以及每模型设置、自动压缩、重试和换网恢复。

## 使用入口

**外观**：设置 → 偏好 → 主题。配色主题与聊天布局各自独立。新外观设置默认使用工作台布局，可切回经典或专注；原“工作台界面”开关仍只负责用量统计的呈现。

**工作区权限**：扩展 → 工作区 → 本地工作区 → 基本 → 访问权限与挂载。

## 验证与边界

本轮重建后：JVM 1996 项，1995 通过、0 失败/错误、1 项原 PDF 语料跳过；Android 103 项全过，含新增浅深主题前景回归；存储拒绝/授权/撤销三段各 1 项通过；Ubuntu 24.04.3 真实 Rootfs 动态目录映射 2 项通过；r5 → r6 同签名覆盖、数据 marker 保留与冷启动检查通过。签名、包体 SHA256、大小和日志摘要见附件 `r6.json`。

附图为隔离 AOSP API34 模拟器上实际签名 Release 的聊天页，覆盖工作台浅/深色、专注深色、经典浅色；样例对话为合成测试数据，不是用户聊天或账单。没有自动安装到用户手机。

PRoot 目录映射不等于内核 mount，PRoot 显示 root 不等于 Android Root。Shizuku 与 Root 由用户现有服务/管理器授权，安装本应用不会给普通设备 Root。本轮未证实 Shizuku 正向执行、App su Root 正向执行；模拟器 shell 可用 su，不代表应用拿到了 Root。系统 SELinux、跨 App 私有数据与 Root 后代进程回收边界不变。

Android 12 以下保留安全遮罩和前景，壁纸模糊不承诺同样效果。Gemini/Claude 网页账号仍是 r4 实验功能，本轮没有修成“登录后自动可用”，也没有内置 CLI、Node 或浏览器引擎替代。
