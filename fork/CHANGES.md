# 与原版的差异 / Differences from upstream

基线：RikkaHub `3.1.1`（commit `ad2c4430`）；上一版基于 `3.1.0`（`eeef60b2`）。

当前能力对比统一见 [FEATURES.md](FEATURES.md)：工作流、体验增强、稳定性修复与继承官方的能力分开说明。下面是按版本保留的历史记录，旧版本的行为不代表当前实现。

## 3.1.1-r19：图片并发与语音调节（2026-11-05）

- 图片整理增加可保存的 1–16 路并发，默认 3 路；固定工作协程处理，缓存、取消和单张失败隔离保留，模型共享上限仍生效。
- 语音页集中选择朗读语言、0.25–3 倍语速、音高和音量；系统 TTS 可选择已安装音色，OpenAI 增加语气指令，设置跨重启保存。
- 当前段优先合成，首段缩短，移除固定段间等待；限制预取并释放播过的音频，常见云 TTS 请求可在停止时取消。
- 生图没有收到图片数据时，结束/失败/取消会清掉空图片并落库；打开旧会话和发给模型的历史也会过滤空占位，保留有效图片与用户附件。
- 客户端按段播放，不宣称所有接口都能字节流播放；短段/预取可能增加请求和费用，不保证上游提速。[r19 说明与边界](RELEASE-r19.md)。

## 3.1.1-r18：输入清理、可靠队列与网络恢复（2026-11-05）

- 发送回执改成可靠入队确认，不再等前一轮生成完成和消息落库才清输入；新追加的字与附件保留。
- 待发送消息按会话原子落盘，记录出队尚未提交的 inFlight，稳定 UUID 去重并保留原助手归属。
- 网络恢复接线到失败轮次和待发队列；网络、用户停止、普通错误暂停分开，未打开的会话也能继续。
- 从已完成步骤恢复文字请求，保留工具结果；不重放已开始而结果不明的工具，不绕过审批。

## fork.43：工具调用层重做（2026-11-01）

- 同批独立只读调用并发执行（并发上限 8），写操作与语义未知的工具仍是顺序屏障；同批同名同参数的只读调用只执行一次，结果共享
- `tool_batch` 并发执行与批内去重；成员失败不影响其余调用；成员审批判定抛异常时失败关闭（要求审批），不再静默放行
- MCP 工具数 ≥16 或估算体积 ≥20000 字符时改用精简目录 + `tool_search`（默认 6、最多 8 条）/`tool_call`，不再整表塞进请求
- 工具输出文本合计 >16K 字符时外置到应用私有目录：回执 + 头尾各 2K 预览，`tool_output_read` 按字符 offset/limit 分页读回；保留 7 天、最多 64 份输出，按 32MB 预算轮转（至少保留最新一份），按会话归属；取消按后端与工具名关闭外置的旧开关
- `workspace_read_file` 支持 `offset`/`limit`（默认 2000 行、最多 20000 行，回带 totalLines/hasMore/nextOffset）；新增 `workspace_grep`、`workspace_glob`（默认跳过 .git/node_modules/build 等、二进制与 >2MB 文件，20000 文件 / 15 秒预算）；两者仅限文件仍在本机的工作区，SSH 明确拒绝并提示用 `workspace_shell`
- 子代理结果支持分页（默认 6000、最多 12000 字符，带 nextOffset/totalChars/eof）；并发默认 4、可设 1–8，并按 `ActivityManager.memoryClass` 自动降到 4 或 2

## fork.41：结束命令时结束整棵进程树（2026-11-01）

- 原因：Android 的 `destroy()`/`destroyForcibly()` 都只发 SIGTERM，PRoot 忽略；ART 屏蔽 SIGQUIT，PRoot 收到 SIGQUIT 结束全部进程的逻辑不会触发；SIGKILL PRoot 只会让命令脱离跟踪继续运行
- 新增 `ProotProcess`：按启动时的环境变量标记找到 PRoot，信号直接发给被跟踪的进程（父进程在前），由 `--kill-on-exit` 带走其余进程；每次发信号前重读 `/proc`，不会打到被复用的进程号
- 后台命令与任务在 TERM trap 下运行：收到结束请求后不再执行剩余命令，等已启动的进程收尾，以 143 退出
