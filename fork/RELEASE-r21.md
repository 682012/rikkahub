# RikkaHub 3.1.1-r21 · Agent 架构大更新

版本 `3.1.1-r21 / 3000068`，包名 `me.rerere.rikkahub.fork`，正式包 45,842,374 字节（43.72 MiB），SHA-256 `623e7ebde54f604e95df25d8c6ddd04874937a71ec51291a306c1b3042b167c9`。仍用 r20 的原证书签名，同包名的本分支版本可直接覆盖升级；已发布的 r20 标签与资产不动。**升级前请备份聊天、设置与工作区，不要为了升级先卸载。** 数据库由 schema 34 升到 35（会话表新增「家族根」和「归库锁」两列），首次启动自动迁移，旧行用 `COALESCE` 兜底、不需要回填。

本次主要更新：Agent 主循环、子代理与步数、会话/记忆/队列归属、断线恢复、经验学习、会话列表与归库、工具参数草稿、时间与字符统计、工作区网页渲染都重做过一遍，另外增加一套可选外观。下面按「你会看到什么」写，逐条实现与限制见 [docs/r21-agent-core/CAPABILITIES-r21.md](../docs/r21-agent-core/CAPABILITIES-r21.md)。

## Agent 主循环与子代理

- 工具声明在整次运行里按名字建一次索引，取代每次调用都线性扫一遍；工具参数的规范化结果按参数原文缓存，同一步里不重复解析。
- 原地打转的检测从「连续同一个调用」扩到**周期**：同一调用连续 4 次结果不变就拦，ABAB 这类交替振荡也能识别（周期最多 4，需看到 4 个完整周期）。只对纯文本输出成立，带图片/文件的结果一律保留；轮询类工具豁免。
- 发给模型的副本里，重复的纯文本工具结果（400 字符以上）折叠成一行指向更早那次调用，**消息与界面仍保留完整结果**；替换只依赖更早的内容，同一段历史每次结果一致，不破坏提示词缓存前缀。
- 审批后继续、工具续跑这类「接着跑同一条消息」，**继承这条消息已用的步数**，不能靠反复续跑换出额外预算；只是继续写回复时仍是一次全新预算。上限判断改成「大于等于」，继承后已超限也能停住。
- 子代理排队、取消、后台交付与「完成通知不唤醒新一轮」的规则一起保留：完成类通知以不唤醒方式入队，空闲时不会自己发起模型请求，只在已有或你发起的下一轮被取走。

## 会话、记忆与队列按助手隔离

- 会话所属助手被删除时不再回退到「当前助手」：会话拿到同 ID 的空占位（无记忆、无工具、无工作区、无技能、无注入），生成入口给出明确错误，而不是把别的助手的人格和记忆串进来。
- 记忆库恒按助手隔离，旧的全局共享开关只为读旧数据保留；跨助手只有你主动迁移：迁移只搬对话本身，配置快照、模式注入与 Lorebook 按目标助手重拍，旧工作目录、文件夹、会话级 system prompt、聊天建议和压缩摘要不跟过来。
- 旧共享记忆的复制是你点的一次性动作：**目标助手已有的同名文件不覆盖**，与编辑操作串行；不自动同步，也不自动删除旧库。
- 对话检索工具（最近对话、搜索、读取）都收窄到当前助手范围；抽屉的会话列表按助手取；待发队列在消息清空后才允许换归属，旧助手未发出的通知不会被带过去。

## 持久队列与断线自动恢复

- 自动恢复只处理「网络断了不用你手点」：用户停止、等待审批、鉴权/配额/请求格式/权限、本地落库失败以及**副作用未知**一律不自动重发，宁可不恢复。
- 已开始但结果未知的工具、尚未完成检查点的生成媒体不自动重放；已完成并落库的工具结果留在检查点，接着请求模型，不重新执行工具。工具的 start 与每次完成结果都先落库再继续。
- 恢复前核对会话代际、同一条用户消息与失败尾巴都没变，从完成的检查点续跑，并把中断草稿留成独立分支；整轮默认最多 3 次自动拉起（上限沿用你的重试设置），票据 10 分钟过期，超时给终态提醒。
- 一个会话只占一个恢复通知身份，进度卡只更新一条、不响不震；完成通知只在真正完成时才带内容预览，每条完成通知有自己的会话 tag，点击用的 PendingIntent 按用途分开，不会跳错对话。

## 每助手经验学习：统计与确认，不是训练

- 每个助手一份本地 JSON，只记轮数、工具调用与失败、重试、是否触顶、重新生成次数与耗时；不存正文、思考、工具参数与返回值、凭据，也不额外发起模型请求。
- 经验只有两种：按固定模板从指标算出、至少 3 轮重复证据的「自动统计」（不落盘），和你自己新增或确认的条目（落盘）。注入最多 3 条、共 1800 字符，只取本助手同模型的证据，不覆盖主设定、你的要求与权限。
- 上限与恢复：每助手 200 轮指标、24 条经验（18 人工 + 6 自动）、单文件 4 MiB；写前加锁、tmp/fsync/rename；坏文件先唯一备份再恢复，读不到开关按关闭处理；未知 schema 或助手 id 不符直接报错，不重绑归属。关闭后停止收集与注入，旧数据保留可删。
- **不训练或微调模型权重、不下载模型、不新增权限**；计数与耗时不等于质量分，**不保证每轮性能单调提升**。

## 会话列表：分叉家族折叠

- 从一条会话分叉出来的分支现在带显式家族根，抽屉与文件夹里同一家族只出一张卡，带成员数量角标，点开才展开全族；置顶会话仍逐条显示。
- 旧数据按「开头那条真正由用户发出的消息 ID」保守补认；新会话贴进来的预设开场消息共享同一个 ID，按预设列表与时间判据排除，不当成分叉。认不准、证据互相打架的一律当各自是根——宁可多一张卡，也不把两条不同对话并成一族。
- 家族按助手和文件夹隔离，不会跨助手合并；搜索仍列出全部匹配，不受折叠影响。这一层只改展示口径，不合并、不删除任何会话。

## 相似话题归库（默认关闭）

- 默认关闭。开启或手动点一次「立即整理」都会先把闲置会话的标题与限长首尾摘要发给**你配置的快速模型**，面板里明确写出「会外发、会消耗 API 额度、默认关闭、每批可撤销」。
- 候选只取同助手、未置顶、未手动上锁、当前不在任何文件夹、闲置超过设定小时（默认 36 小时，可设 24–168）且有标题的会话；同一家族只取最早创建的一条做代表，兄弟不额外过模型，也就不会多花输入。
- 模型返回严格 JSON，置信度低于 0.85 不采纳；新文件夹要求至少 3 个不同家族，文件夹总数不超过 12；代表被采纳后同族合格成员一起跟随，单批搬迁上限 200 条。
- 每批写日志，可整批撤销；你手动归好库的会话会被上锁，之后的自动整理不再动它。它只改归属，不改内容、不删会话。

## 工具代码实时草稿

- 文件写入/编辑、shell、代码与脚本、网关这类长参数在生成过程中就能看到，约 500ms 节流落库，并补写最后一个 delta，停在最后一块也不会只留在内存里。
- 半截 JSON 可以预览、复制、导出，但**不会执行、不会进入审批**；增量正确处理转义与 Unicode，重写同长度内容不会复用旧预览。
- 超出预览上限时，复制与导出退到完整已收原始参数并明确告知，避免静默导出半截内容。
- 中断后会保留被中断的那条回复分支，工具参数完整状态单独持久化，正常结束、截断、异常与取消分开记录，旧记录保持兼容。
- 不做两个承诺：**不宣称断电零丢失**（节流落库只是缩小窗口），也**不宣称草稿已经逐字写进目标工作区**（那要工具真正执行才发生）。

## 时间、字符统计与工作区网页

- 主对话 Agent 每步请求都取当前设备时钟并携带时区偏移，取点放在 OCR/网页读取之后；历史消息里的时间按历史显示，不冒充现在。
- 消息条显示真实结束时刻，详情分开显示开始与结束；全程耗时与模型请求耗时不再混成一个数。
- 正文字符按 Unicode 码点统计（含标点、不含空白），与上游 token 分开列，不把思考与工具输出算作正文。
- 工作区 HTML/SVG 主文档改内存直载，保留同目录资源、脚本与网络开关；应用 CSP 叠加页面自身策略；补充错误提示、重试、渲染器重建与手动「兼容渲染」入口。已在 Chromium 上把原页面完整渲染出来，**新 APK 的真机 WebView 还没点验，根因也没在真机上证实**。

## 外观与快捷入口

- 聊天风格在经典 / 工作台 / 专注之外新增**轨道（ORBIT）**：贴着状态栏的紧凑任务栏，加一条常驻运行态轨道（当前模型、速度、上下文、运行态圆点在同一条轨上）；窄屏或大字体时自动收掉上下文表盘。新枚举值追加在末尾，旧配置照旧能读回，既有三种风格的参数一个都没改。
- 启动动效可选**轨道环 RING**（默认）/ **DOTS** / **OFF**（不画）。只在冷启动且从桌面正常进入时播放，分享、通知、深链接、快捷方式一律不画；同一进程只演一次；系统关闭动画时整段跳过。
- 下拉快捷面板新增**小宠物**磁贴：只读写已有的悬浮窗开关，与设置页改的是同一个值，不新增字段、不起前台服务、不持有悬浮窗。
