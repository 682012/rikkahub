## 后台图片整理

- 页面与通知的取消绑定具体任务 ID，旧通知不能取消后来新建的任务。取消状态写入队列存储，进程恢复时不会把已取消批次当作等待执行。
- 自动批次带独立归属。关闭自动整理时停止所属自动任务，不误停手动批次；扫描期间关闭开关也会在入队前重新检查。
- 前台服务启动失败、后台执行失败和系统中断分别处理，更新错误或暂停状态，不让界面一直卡在“排队”。可恢复的未执行内容保留手动继续入口。
- 无法读取的旧队列先持久关闭自动整理，再隔离损坏文件，保留排查材料。不会因恢复失败而自动重新上传图片。
- 不确定已发送结果的请求不自动重放，不以重试掩盖可能重复计费。

## 分享文字与附件

- 大段分享文字保存在应用私有文件中，导航只携带随机 UUID，避免全文进入导航保存状态。
- 保留完整文字，单份上限 4 MiB、待处理总量上限 32 MiB/128 份，过期缓存按 7 天清理。超过限制或读取失败明确提示，不静默截断；可改为分享文本文件。
- 读取与写入放到 IO 线程，导入失败可重试；保留已有输入，避免覆盖用户后来输入的文字。
- 补充附件名称和 MIME 类型回退，限制外部 Intent 的 URI 扫描数量；导航不接受调用者提供的文件路径。

## Agent 主循环：少分配、认得出原地打转、步数不被套现（草稿）

- 工具声明在整次运行里按名字建一次索引，取代每个工具调用都线性扫一遍声明列表；工具参数的规范化结果按参数原文缓存，同一步里不重复解析。
- 重复检测从「连续同一调用」扩到**周期**：同一调用连续 4 次结果不变就拦；ABAB 这类交替振荡也能识别（周期最多 4，需看到 4 个完整周期）。只对纯文本输出成立，带图片/文件的结果一律保留；轮询类工具豁免。
- 发给模型的副本里，重复的纯文本工具结果（400 字符以上）折叠成一行指向更早那次调用，**消息与界面仍保留完整结果**；替换只依赖更早的内容，同一段历史结果稳定，不破坏提示词缓存前缀。
- 审批后继续、工具续跑这类「接着跑同一条消息」的情况**继承这条消息已用的步数**，不能靠反复续跑换出额外预算；只是继续写回复时仍是一次全新预算。上限判断改成「大于等于」，继承后已超上限也能停住。

## 助手隔离与显式迁移（草稿）

- 会话所属助手被删除时不再回退到「当前助手」：会话拿到同 ID 的空占位（无记忆、无工具、无工作区、无技能、无注入），生成入口给出明确错误，而不是把别的助手的人格和记忆串进来。
- 记忆库恒按助手隔离，旧的全局共享开关只为读旧数据保留；跨助手只有用户主动迁移：迁移只搬对话本身，配置快照、模式注入与 Lorebook 按目标助手重拍，旧工作目录、文件夹、会话级 system prompt、聊天建议和压缩摘要不跟过来。
- 旧共享记忆的复制是用户点的一次性动作：**目标助手已有的同名文件不覆盖**，与编辑操作串行；不自动同步，也不自动删除旧库。
- 对话检索工具（最近对话、搜索、读取）都收窄到当前助手范围；抽屉的会话列表按助手取；待发队列在消息清空后才允许换归属，旧助手未发出的通知不会被带过去。

## 经验学习：只统计与用户确认，不训练权重（草稿）

- 每个助手一份本地 JSON，只记轮数、工具调用与失败、重试、是否触顶、用户重新生成次数与耗时；不存正文、思考、工具参数与返回值、凭据，不额外发起模型请求。
- 经验只有两种：固定模板按至少 3 轮重复证据算出的「自动统计」（不落盘），和用户自己新增/确认的条目（落盘）。注入最多 3 条、1800 字符，只取本助手同模型的证据，不覆盖主设定、用户要求与权限。
- 上限与恢复：每助手 200 轮指标、24 条经验（18 人工 + 6 自动）、单文件 4 MiB；写前加锁、tmp/fsync/rename；坏文件先唯一备份再恢复，读不到开关按关闭处理；未知 schema 或助手 id 不符直接报错，不重绑归属。关闭后停止收集与注入，旧数据保留可删。
- 不训练或微调模型权重、不下载模型、不自行提权；计数与耗时不等于质量分，**不保证每轮性能单调提升**。

## 断线恢复与通知（草稿）

- 自动恢复只处理「网络断了不用用户手点」：用户停止、等待审批、鉴权/配额/请求格式/权限、本地落库失败、以及**副作用未知**一律不自动重发，宁可不恢复。
- 已开始但结果未知的工具，以及尚未完成检查点的生成媒体，不自动重放；已完成并落库的工具结果留在检查点，接着请求模型，不重新执行工具。工具的 start 与每次完成结果先落库再继续。
- 恢复前核对会话代际、同一条用户消息与失败尾巴都没变，只替换被中断的那个分支；整轮默认最多 3 次自动拉起，上限沿用用户重试设置；票据 10 分钟过期，超时给终态提醒。
- 一个会话只占一个恢复通知身份，进度卡只更新一条、不响不震；完成通知只在真正完成时才带内容预览，每条完成通知有自己的会话 tag，点击用的 PendingIntent 按用途分开，不会跳错对话。
- **不自动开付费轮次**：子代理完成与后台工具完成的通知入队时标记为「不唤醒」，空闲时不会自己发起一轮模型请求，只在已有或用户发起的下一轮被取走。通知先写进会话再确认出队，持久标识防止「历史已写入、队列未确认」时的重复交付。

## 聊天风格与启动动效（草稿）

- 聊天风格在经典 / 工作台 / 专注之外新增 **轨道（ORBIT）**：贴着状态栏的紧凑任务栏，加一条常驻运行态轨道（当前模型、速度、上下文、运行态圆点在同一条轨上）；窄屏或大字体时自动收掉上下文表盘，按钮不被挤掉。新枚举值追加在末尾，旧配置照旧能读回；既有三种风格的布局参数一个都没改。
- 启动动效可选 **RING**（轨道环 + 沿环光点，默认）/ **DOTS**（光点向内聚合）/ **OFF**（不画）。只在冷启动且从桌面正常进入时播放，分享、通知、深链接、快捷方式一律不画；同一进程只演一次；**系统关闭动画时整段跳过**。
