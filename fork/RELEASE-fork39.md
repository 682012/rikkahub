## 另修了一个真实升级问题

fork.38 的更新检测仍访问官方更新源，SemVer 又把 `3.1.1-fork.38` 排在官方 `3.1.1` 后面，实际会显示“发现 3.1.1 新版本”，并给出无法覆盖本分支的官方安装包。

fork.39 改为读取本仓库 GitHub Releases 的最新正式包，解析 fork tag、APK 和体积，忽略校验附件；没有 APK 的发布不会被当成更新。只改变更新来源，不自动安装，也不改变官方应用。

## SSH 入口与实际验证

入口：**设置 → 扩展 → 工作区 → 右下角加号 → SSH 远程工作区**。全局“高级与长任务 → 远程执行”是 fork 的 HTTP 命令服务，不是 SSH 配置入口。SSH 不需要安装本地 Rootfs；在聊天/助手中还需选中相应工作区。

fork.38 的 SSH 代码和加号入口没有漏合：把对应 Release 原包安装到隔离模拟器，已实际看到 SSH 选项并打开配置页。fork.39 则进一步通过 Android App 全链路验证：从系统文件选择器导入测试密钥、核对并信任主机指纹、创建工作区、SFTP 列目录、打开并读取 `hello.txt`、启动 SSH 终端执行 `pwd`，返回测试服务器工作目录。

这说明本包的 SSH 链路跑通，不代表用户自己的主机、凭据、网络和厂商后台策略都已验。
