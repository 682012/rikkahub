# RikkaHub 3.1.1-r5 · 会话工作台与统计修正

实验版，基于 r4 全部功能继续开发。稳定版 r3 与旧 r4 不撤回；版本码 3000052，包名、原签名、schema34保持。

## 这轮改什么

- 新增工作台显示模式：聊天顶部上下文状态条、独立会话仪表板。设置 → 偏好 → 界面 → 工作台界面切换；面板内也能直接切经典明细。选择持久保存，数据与统计规则共用，不维护两套账本。
- 单对话统计从一次性读取改成数据库实时订阅。按全部、主对话、子代理、辅助请求切换，显示可读模型名，模型删除后保留名称快照。查询在数据库先聚合，不把全部流水堆进界面内存。
- 累计消耗与上次上下文分开。累计输入会重复包含每次请求携带的历史，这是消耗口径；上次上下文只看单次 input+output，不冒充下一次请求的精确预算。压缩后无新上游报告时显示未知；旧多步骤缺少单次usage时不再拿累计值充当窗口。
- 缓存是输入的子集，不重复计入合计；未上报缓存不等于未命中。缓存上报超出输入或为负值时保留原数并标异常，不偷偷裁成看似正常的计数。主数字支持点按查看精确计数，短单位只负责显示。
- TPS改为客户端流式吞吐：识别有效正文/推理/工具参数增量，元数据不启动时钟、尾部usage不延长输出时长；分开显示最近首内容延迟、模型请求耗时和吞吐。多步按总输出/总有效流时长计算，不平均各步速度。
- 一次性缓冲、短于200ms的样本、非流式、缺usage、旧记录缺计时、已识别的服务内部续写或包含无法分离的服务端工具等待，不伪造TPS。上游completion口径可能含推理，不当作正文独立分词或服务器推理引擎速度。统计模型请求耗时不含本地工具/审批等待；失败重试成本仍由用量流水记录。
- 全局用量页面随新增记录刷新。
