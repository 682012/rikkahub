# r6 外观与沉浸壁纸

入口：设置 → 偏好 → 主题。聊天布局、壁纸设置与原有配色主题分开；原来的工作台统计开关仍在“界面”，它只切换同一份用量账本的呈现，不影响聊天布局。

## 三种真实布局

- 经典：保留 r5 的标题栏、左右消息、贴底输入形态。
- 工作台：浮岛标题栏、上下文条、圆角卡片和浮动输入面板；所有用量、预览、抽屉、模型、文件、语音、工具审批入口保留。
- 专注：收敛标题栏，按需查看统计，放宽消息间距，限制大屏阅读行宽；没有另建会话或另一套统计。

## 壁纸

系统相册选择图片后复制到应用私有目录 `appearance_wallpapers`，不用临时 URI 冒充持久素材；图片文件上限 64MB。也可填写 http/https 图片链接。全局壁纸可以沉浸到聊天、设置、助手、工作区等页面与系统栏背后；关闭沉浸后，全局图只用于聊天。具体会话的助手背景或渐变优先，恢复历史会话不使用抽屉当前助手的壁纸。

支持可见度、主题色遮罩、模糊、铺满裁切/完整显示和九宫格焦点。模糊使用系统 RenderEffect（Android 12+），旧设备保留遮罩与安全前景，不能宣称旧设备也有同样模糊。前景透明度依据主题正文色对黑白两端的对比取安全下限，复杂照片也不能让输入和正文裸露。低对比自定义主题不会因透明变得更差，但主题本身不自动等同 WCAG 合规。

图片加载失败回到实色页面，不只显示一个透明空层。状态栏与导航栏采用主题色渐变保护；不隐藏系统导航，不移除键盘与安全区 padding。Haze 模糊/玻璃沿用已有组件，不新增浏览器或整套外部 UI 引擎。

## 备份、性能与边界

本地壁纸随“文件”备份；恢复时仅重定位本应用壁纸目录，不重写其他路径或网络地址。按工作区的提权、挂载和信任授权仍在 noBackup，不被备份迁移为授权。移除壁纸只删应用自有目录内的图，不碰用户相册。

Coil 按视口解码，前后景共用原来的原生 Compose；不把原图以 Bitmap 常驻、不引入 Node/CLI/UI 浏览器。实际包体、JVM/Android测试、覆盖安装及截图以本轮 verification/r6.json 为准；未完成的项不得沿用 r5 的测试数字。
