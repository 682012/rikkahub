# Meridian 3.1.1-m3 · 工具审批与会话修复

版本 `3.1.1-m3` / `3000072`，包名 `me.rerere.rikkahub.fork`。沿用原签名，一个通用 APK，包含 arm64-v8a / x86_64；可覆盖升级 m2 及同签名旧版，不要卸载。旧 Release、tag 和附件保留。

## 工具调用

- 设备手势与六个高权限 `android_*` 工具接入工作区的工具审批配置。状态、设置查询、安装包列表默认不弹确认；写设置、自由高权限 shell 与敏感日志默认需要确认，可以分别配置。
- 工作区 Linux / Android 自由 shell 默认不弹确认，分别保留用户已有覆盖项。关闭审批不等于得到设备权限；真实授权、助手绑定、Shizuku、独立写开关和幂等账本仍检查。
- WebAccount 不再偷偷把所有工具改成强制确认。各工具遵循自己的审批策略。
- `tool_batch` 按成员判断审批，界面列出需要审批的成员，可全部批准或只批准某一条；未批准的写操作不执行，返回结构化拒绝。只读且无需审批的成员不被当作拒绝操作。批内有待确认成员时仍会等待这次选择。
- 审批展示工具名与脱敏关键参数，包括命令、设置键和包名，长内容截断，避免盲签和直接展示密钥。

入口：工作区详情 → 基础 → 工具审批 / 设备工具审批。

## 会话与分组

- 会话列表减少分页刷新时重复定位；原列表就地显示可展开组头，展开后仍是独立会话，可以移出组，不合并消息与上下文。
- 主列表按家族根显示，分支会话从家族入口查看；查询仍限定当前助手。
- 已初始化会话重新进入时恢复内容就绪状态；已有消息不会因短暂加载标记被替换成空白或假加载气泡。
- 输入优化和独立回复审查分别选择模型。未选择时跟随本会话聊天模型，不再隐式借用快速模型；同模型自检仍不额外发审查请求。
- 新会话本地知识库默认开启；旧配置中显式关闭的选择保留。命中片段随请求发送，会占用输入 token。

## 六花启动动画

真正的六花实现已从旧工作树接入主线，包括六瓣绘制、默认风格、选择入口和预览；原环、光点、柔光仍保留。旧用户已保存的风格不强制迁移。

内建动效默认 1500ms，可调 200–2300ms，预览与冷启动读取同一设置。支持关闭，系统减少动画时不播放；分享、通知、深链接和热恢复不重复播放。

入口：偏好设置 → 主题 → 启动动效。

## 本机 MCP、经验与重试

- 修复本机 MCP 已启用设置恢复时，设置值未变化而未真正启动服务的问题；保留端口占用、绑定失败等实际错误，不用笼统前台服务错误覆盖。
- 每助手经验面板增加每轮总结开关，默认关闭。开启后任务终态触发独立模型总结，将通过筛选、脱敏、去重的可复用经验写入助手自己的记忆文件及本地知识库。取消、等待审批不当作成功；额外模型请求照常计费。没有声称训练或微调模型。
- 额外重试规则可新增、编辑、删除，采用有长度限制的文本匹配而非任意正则；保存后进入实际分类。自定义错误不会绕过非幂等写操作的禁止重放边界。
- 修补渠道故障切换设置的持久化注册，避免重启丢失选择。

## 提示词缓存

缓存时长按实际协议发送，不是修改 App 图片或网络缓存的过期时间。

- Anthropic 沿用已有 5 分钟 / 1 小时 `cache_control.ttl`，不虚构一天档。
- OpenAI 旧保留协议可显式选择 24 小时；新 TTL 协议提供 30 分钟，以及 Responses 的 12 小时。渠道默认不多发缓存字段；不支持的协议组合明确报错，不静默缩短时长。
- 网关和模型必须实际支持所选字段；缓存保留不保证命中。写入价格按厂商、模型与档位计算，长期缓存不等于免费。

入口：提供商 → 编辑模型 → 基本 → 提示词缓存保留时长。

## 本轮追加的会话控制

- **自建模型排序池**：自行多选已配置的聊天模型、添加移除、上下排序，跨模型 ID 和提供商，不再限定同名分类组；启用后按池首项建立请求，故障后只切到池内同协议成员。跨协议成员暂不参与切换，界面标明。旧分类组模式仍保留。
- **异常停止自动续接**：网络设置内独立开关，默认关；明确的步数上限停止可从当前回复继续，不新增用户“继续”消息。已有网络检查点恢复保留。最多 1–10 次，默认 3；正常完成、人工停止、待审批、未知工具副作用不触发。不能保证厂商缓存命中，也不把模型主动结束一律判断成异常。
- **优化/审查角色提示词**：两项独立编辑、按会话保存，清空恢复默认；原话优化缓存含角色与所选模型指纹，换角色不会复用旧结果。独立审查和同模型自检都读取审查角色，不改变工具权限与输出契约。
- **会话推进提醒**：默认关、鼓励/中性语气，每条回复 1–3 次、默认 1；只对行动请求中“只报计划却没执行工具”的保守信号提醒，不另开评审请求，但继续生成会产生模型用量。沿用当前步数预算，不越过审批、停止和安全边界。属于启发式，不声称可靠判断“偷懒”。
- **自然角色代入**：保持已选助手人设与表达连续，减少无关人设分析、重复身份声明；不编共同经历，事实、身份、权限与执行结果照实说。会话选项可关闭，无额外模型请求。
