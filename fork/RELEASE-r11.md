# RikkaHub 3.1.1-r11

接续已发布 r10，版本码 3000058，包名、原签名、应用名和图标不变。保留沉浸聊天、角色立绘、AI小助手、TPS统计与图片历史压缩。

## 本轮变化

1. **长正文默认状态**：设置 → 偏好 → 界面 → 长正文默认状态，可选默认展开或默认收起；本次进程内每条消息的手动选择优先，重启后按设置的默认值显示；流式生成中不自动折叠。
2. **输入草稿**：文字、附件引用、光标和编辑状态保存到应用私有目录；已有对话按对话区分，新对话按助手区分。切对话/助手、离开页面可恢复。发送后等用户消息落库确认才清理，失败保留，新输入不被迟到确认清掉。
3. **记忆与提示词缓存**：相同内容不重复写入/变更版本；记忆清单按路径稳定排序；AGENTS相同内容只注入一次，有界缓存与文件变更复核；本机发行版信息复用。没有把“减少读盘/稳定前缀”冒充供应商实测缓存命中率。
4. **文件预览**：工作区HTML/HTM/XHTML/SVG直接预览并可切源码；启用脚本、同目录资源限定读取，不给网页文件系统/JS桥访问。外部资源默认关闭，可显式打开。新增Markdown阅读、CSV/TSV表格、JSON格式化、EPUB按目录章节提取文本。普通聊天HTML/PDF/文本附件也增加应用内预览。原PDF、Office文本、压缩包清单、图片和音视频入口保留。
5. **Pi/CodeMode工具效率**：静态工具指导集中且不按工具重复注入；已知入口直接复用、定位后分页读取、独立任务同轮并发。项目内AGENTS.md去重与失效复核，不修改用户助手人格。当前工作区的Pi/CodeMode操作约定另在 `/workspace/pi-codemode/AGENTS.md`，没有自动改写全局助手文件。
6. **后台工具**：设置 → 偏好 → 常规 → 后台工具，默认30秒，可调1–3600秒。耗时调用继续同一次执行，不取消重跑；`background_tool`提供start/list/result/wait/cancel。模型收到task_id后可先做无依赖工作；同会话写/未知工具仍排队，独立只读可继续。保留审批，后台完成提醒不会主动发起新的模型请求。进程中断标未知/已中断，不自动重放副作用。
7. **后台压缩与通知**：点击手动压缩后即可离开页面；完成通知可返回原对话。设置 → 偏好 → 通知 → 压缩完成通知独立控制。相同会话重复点击去重；提交前比对消息分支和正文，压缩期间新增尾部消息保留，范围内被编辑则丢弃旧摘要。原图与附件不删除。
