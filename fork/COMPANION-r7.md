# r7 悬浮角色、文件预览与可读性

r7 继续使用项目已有的 FloatingX 和原生 Compose，没嵌入 Electron、Node、CLI 或新的浏览器运行时。

## 参考

- [BongoCat](https://github.com/ayangweb/BongoCat)：Apache-2.0。参考点击立刻给动作反馈的交互节奏，不复制角色图或桌面输入监听实现。
- [OpenPets](https://github.com/OpenPetsHQ/openpets)：MIT。参考任务状态驱动角色表情、提示与面板。只接本客户端已有的任务/审批状态，不开启插件代码执行。
- [FloatingX](https://github.com/Petterpx/FloatingX)：MIT，项目原有依赖。继续复用系统浮窗、拖动、贴边、位置保存与隐藏生命周期。

2026-11-03 实际 GitHub API 快照：BongoCat 24,449 stars，OpenPets 1,373，FloatingX 1,512；只作为社区使用度线索，不当作效果或安全保证。

## 实现

- 保留应用图标，新增原创猫咪、小龙，以及用户自己的待机图和点击图。名字、点击台词、尺寸、动效可改；设置预览能直接点击。
- 原生角色有呼吸/眨眼/耳尾联动，点击给弹跳抬手、短台词与粒子，随后打开原进度/工具审批/快速回复面板。拖动不误触，连点不重放操作；隐藏时停止循环动效。
- 图片先复制到应用私有 floating_companions，16MB和尺寸上限；保存成功后才回收旧图，随文件备份并重定位。
- 壁纸取24×24颜色样本协调主题面板，保留原浅深色与AMOLED。可关闭“按壁纸协调配色”；分组标题、压缩摘要标签加前景保护。
- 当前提供商和模型独立全宽行，不挤在会话标题后面；三个布局都显示生成速度。上游未报告可靠流式计时、短突发、非流式、旧消息没有计时时显示 —，不乱估TPS。

## 文件预览

sandbox:/workspace/... 按本对话助手绑定的工作区解析。中文/空格仅解码一次；本地与SSH文件导出到短期cache。SSH产物预览校验realpath，终端和主动文件操作原授权不缩小。

- 图片可缩放；文本/代码只读可选择；HTML静态安全预览，不执行脚本、不自动请求网络或读本地私有文件。
- PDF系统分页渲染；音视频原生播放/暂停；docx/xlsx/pptx/odt是文本预览，明确不还原完整排版；ZIP/TAR/TGZ只列清单。
- 未知格式显示文件信息和前4KB十六进制；保留打开、分享、导出。不是“任何格式都能还原”。
- 工作区文件页的其他格式也走同一应用内预览，保留文本编辑和图片快捷预览。

实际测试和截图以 RELEASE-r7.md 与 verification/r7.json 为准。
