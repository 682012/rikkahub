## 变化

- 后台悬浮窗保留原图标，新增原创猫咪、小龙和自定义待机/点击图片。可改名字、点击台词、大小与动效，设置页能直接点预览。角色点击先给动作/台词，再打开原进度、审批和快速回复面板；拖动不误触，连点不重放工具。仅在用户已授权悬浮窗且后台任务存在时显示。
- 聊天顶部独立全宽显示当前提供商和模型，经典/工作台/专注都有，长提供商名不会吃掉模型名。
- 三套布局都保留生成速度显示。流式计时/用量足够才显示 token/s，旧消息、非流式、短突发等没有可靠速度时显示 —；不按肉眼看到的字数伪造 TPS。
- 壁纸配色可自动协调面板，保留用户的浅色/深色/AMOLED；可关闭恢复原主题颜色。修复壁纸上分组标题和压缩摘要分隔文字发虚。
- 修复 `sandbox:/workspace/…` 文件链接：按本对话助手绑定工作区打开，中文与空格只解码一次，不再把路径甩给浏览器。悬浮预览可跳入同一应用预览页。SSH产物路径检查 realpath，授权终端/普通文件工具的权限不缩小。
- 应用内预览图片、PDF分页、文本/代码、静态HTML、音视频；DOCX/XLSX/PPTX/ODT提供明确标记的文本预览，ZIP/TAR/TGZ列清单，未知文件有信息与前4KB十六进制预览。工作区文件页的其他类型也接入同一预览，保留打开/分享/导出。

## 入口

角色：设置 → 偏好 → 通知 → 悬浮角色；上方“后台悬浮窗”开关需用户授权。

壁纸配色：设置 → 偏好 → 主题 → 按壁纸协调配色。

文件：点聊天中的工作区文件链接，或扩展 → 工作区 → 文件；文本编辑与图片快捷预览保留。

## 边界

- 自定义图片存私有 `floating_companions`，16MB与像素尺寸上限，保存完成后再回收旧图；随文件备份并重定位。未内置 Electron、Node、CLI、Office引擎或新的浏览器运行时。
- HTML静态预览禁脚本、网络请求、本地文件/content访问与JS桥。Office文本预览不等同完整排版；旧doc/xls/ppt、7z等未承诺原生排版/解压。音视频可播放取决于系统codec；预览失败仍可打开/导出。
- 文件链接只指当前工作区，有256MB临时导出上限，文本预览2MB；不存在的文件给明确错误，不会凭链接从别处凭空下载。
- 模拟器验收不是用户真机安装。Shizuku/App su Root正向、真实供应商吞吐与Gemini/Claude登录即用仍不在本轮认证范围。
