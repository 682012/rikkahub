# 网页会话接入（实验）

Gemini 网页和 Claude 网页作为独立提供商进入本地聊天、上下文压缩及可选的提示词工具协议。不是官网快捷入口，也不把网页会话伪装成 API Key/OAuth。

## 使用流程

设置 → 提供商 → 添加「Gemini 网页（实验）」或「Claude 网页（实验）」：

1. 在真正的浏览器打开官方站点，由用户本人登录。Custom Tabs 与 App 不能共享读取会话；没有伪造 WebView/Chrome 登录。
2. 在 App 的本地会话对话框粘贴该站点 Cookie 请求头或浏览器导出的 JSON。不要把 Cookie 发给聊天助手或上传到中转服务器。只取 Gemini 的 `__Secure-1PSID`/`__Secure-1PSIDTS` 或 Claude 的 `sessionKey`；其余 Cookie 丢弃，不复制浏览器指纹或挑战通行 Cookie。
3. 点「验证并加载模型」。真实读取官网 bootstrap/组织接口成功，才标记这一次验证成功。仅保存本地密文不等于登录通过。
4. 选择「网页默认」模型聊天。此版不声称能指定任意 Gemini/Claude 型号；默认模型由该账号的网页服务决定。Claude 多组织且不能唯一确认个人空间时，必须填写目标组织 UUID，不会任意跨组织。

## 凭据与权限

会话用 Android Keystore AES-GCM 加密，AAD 绑定提供商 UUID 和服务，存于 `noBackupFilesDir`。不进入 Settings JSON、聊天导出、备份、分享、HTTP日志。退出/删除提供商清除本机密文，不退出浏览器，不读删浏览器历史。

端点固定为 `gemini.google.com` 与 `claude.ai`，Cookie 不跟随重定向、不发往自定义 baseURL；保留设备代理路由，不关闭 TLS 校验，不假冒官方客户端。401/403/429、登录页及挑战直接报错，不自动轮询或绕过。会话过期后由用户在浏览器重新登录并再次导入。

Claude 当前官方条款限制第三方代持其网页登录凭据。本实验不代表两家的正式授权；可能无法登录、触发限制或随网页协议变更失效。接受实验不等于服务条款不存在。没有真实账号凭据的测试不能证明账号可用。

## 功能边界

- 首版纯文本。不支持图片、音视频或直接上传附件；可先用已有文档转文本功能。不能处理的内容明确拒绝，不悄悄丢掉。
- 每次请求带本地上下文，创建独立网页会话；可能在官网生成记录，不自动删除用户的远端历史。两家均先收完整响应和终态再交付：这是缓冲输出，不是逐 token 实时流。
- 网页没有通用原生 function calling。可选「提示词工具适配」使用完整 JSON、单次 nonce、工具白名单、参数校验和数量/体积限制；截断、错格式、未知工具不执行。每次调用都进入现有用户确认流程；后台子代理不启用这套工具，后台记忆写入须另选 API 模型。
- 网页接口没有可靠用量上报时，用 UTF-8 长度的保守估算触发自动压缩，绝不冒充服务端 token 或缓存命中统计。默认 32K 是本地预算起点，不是网页真实窗口承诺。
- 实际内容、工具描述和工具结果按用户请求发送到官方服务；“会话只放手机”是指本地存储与不经过我们的服务器，并不意味着官方服务收不到认证 Cookie。

## 当前验收

开发中的测试状态以最终 Release 验收 JSON 为准。单元测试、模拟服务器与 Android Keystore/界面测试能验证实现边界；只有用户在本机导入后完成官网验证与实际聊天，才能验证该账号当下可用。不能把这几件事混为一谈。
