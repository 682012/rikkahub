## 会话与图片整理

历史记录增加搜索、当前/全部助手、7/30/90 天未使用筛选、多选与全选；全选跳过置顶，换筛选清空选择，删除失败项仍保持选中。全部助手的轻量摘要也覆盖所属助手已删除的会话。删除需要确认，不自动清理。

设置 → 文件管理 → 图片整理，可选视觉模型识别分类，再由用户勾选删除或标记保留。范围只含 App 管理的上传图片、旧图片生成和媒体创作输出，不扫系统相册。六类：人物/动漫、截图/文字、风景/实物、设计/图表、其他、未识别。

识别前说明发送给哪个模型及会产生用量，未确认不发请求。保留标记独立持久化；保存失败明确提示，不显示为已保存；多页面实例写入合并，不互相覆盖。删除前复查保留标记与共享引用，媒体创作只删除被选中的输出，不删除整条记录或输入素材。中断的媒体单图删除按记录引用还原或补完，无法确认的保留并提示。

删除不是系统回收站，请仔细确认。主聊天里引用已被用户明确删除的上传图可能失效；共享生成输入则主动跳过。

## 轻量网页预览与公式

普通聊天的 http(s) 链接用 Android 系统 WebView 打开，显示地址、进度、错误与重试，并可在外部浏览器打开。没有打包 Chromium 等额外内核；离页销毁页面实例、缓存有界。不忽略 SSL 证书错误，file/content/javascript/data/blob 等危险导航不在该网页入口执行，自定义外部协议需要确认。

工作区 HTML/离线文件仍走原隔离沙箱，不与公网网页预览混用。网页可加载网络内容，这是打开外部链接的正常网络访问，不是零流量模式。

Markdown 默认注册块级与行内数学渲染，归一化常见 `$$`、align/gather/equation 等写法与块内空行；代码围栏、行内代码、转义美元与金额保持原样。公式不支持或解析失败时显示源码，避免白块；不声称支持所有 LaTeX 宏或完整排版引擎。

## 多图、发送与重连

多图发送可选择一次发送或逐张识别。逐张模式先按所选视觉模型逐张、无工具请求，再把描述交主流程，识别缓存按会话、模型、图片版本和问题隔离。它适用于供应商多图不兼容的情况，会增加视觉请求次数与用量，发送前由用户选择；压缩等不适合重入的路径不自动走逐张识别。

输入状态、错误列表和附件入口按会话绑定；发送成功后只清与已提交快照一致的草稿，不把后续新输入清掉，也不把 A 会话的状态带到 B。新会话草稿同时包含助手与会话 ID。

常规重试遵守用户设置的间隔；网络恢复/切换产生路由变化时提前唤醒等待，不再等完整间隔。在途旧网络请求会取消并交安全文本重试，旧网络丢失事件不抹掉新网络；短暂离线不白白耗尽重试次数。MCP 重连同步感知换网，不自动重放工具调用或图片生成。系统杀进程、上游不可用等仍可能中断请求，不能保证永不断线。

## 六小只完整人设

六角色完整提示词来自独立人设包 v1，约 4500–4800 字符/只，目录位于 `app/src/main/assets/companions/personas/companions-personas.json`。默认全文与包内导出和 SHA-256 对齐，不把内置值写进用户覆盖字段，不叠旧短人设。

在偏好设置 → 通知 → 悬浮角色，可看“内置全文”和“当前生效”，选择/复制全文，展开 App 固定 system 边界，以当前全文为基础编辑或恢复内置。AI 关闭时也能查看复制，不产生模型请求。来源、版本、SHA-256 与 UTF-16 长度在查看器展示；角色正文与完整 system 分开复制，不包含主聊天、密钥或上游不可见注入。

自写人设整段优先。编辑上限 16000 UTF-16 code units，超限明确提示、保留草稿，不再静默截 800；保存只写打开编辑器时的角色，恢复只清该角色人设，不清模型、开关、名字、图片或其他角色。旧版已经截掉的文字无法凭空恢复，需要从原稿重新导入或粘贴。

AI 开启时，每次有效点击按人设和最近真实小助手互动现场生成。示范对话只用于声音参考，开场与原8句不会当随机 AI 答句；8句只保留离线用途。保留一次在途、防抖、取消/迟到隔离、COMPANION 计费与160字符气泡上限，不为变化偷偷重试收费。切角色、改名、人设或生效卡版本变化时旧请求失效。

旧 `cat` 仍是小鲸，`dragon` 仍是小白龙，角色形象不改变实际供应商。主聊天助手的设定不被替换。
