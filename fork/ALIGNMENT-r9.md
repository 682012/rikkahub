# r9 消息气泡对齐修复

r8 增加正文折叠时，`CollapsibleMessageText` 的外层是满宽容器，正文内层 `Column` 却沿用默认 `Start` 对齐。外层用户消息的 `End` 不能穿透这个容器，因此头像和操作栏在右，短文本气泡在左；长文本接近满宽，原验收只测高度又更容易漏掉。

r9 只补正文内层的角色对齐：用户走 `End`，助手走 `Start`。不移除折叠，不改气泡内容宽度、头像、操作按钮、附件位置或数据库；RTL 仍按语义方向处理。保留 r8 立绘、文件预览与顶部摘要。生产行为修改是一处对齐参数，另外只递增版本码并增加回归测试。

新增 8 项实际 Compose 布局断言：短用户、短助手、两段不同宽文本、长用户展开/收起、关闭折叠、流式结束、280dp + 1.3 字号、RTL。测试包含真实 `SelectableContent` 外层，检查横坐标与按钮位置，不只检查高度。

验收另外在隔离模拟器里使用发布的 r8 签名包重现“测试”气泡靠左，再覆盖安装 r9，在同一份合成聊天上比较三布局和大字号的前后位置。测试使用合成 TPS/用量，不是供应商性能测量；本轮不调整 TPS 统计规则，也不会补造旧消息缺失的计时。

最终实测结果、签名、APK 哈希与截图见 `RELEASE-r9.md` / `verification/r9.json`；仅以这些验收文件的真实结果为准。
