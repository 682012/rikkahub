# RikkaHub · 个人增强分支（简体中文）

中文主说明统一维护在 [仓库首页 README](README.md)，避免多份介绍互相过期。

当前版本 **Meridian `3.1.1-m2` / `3000071`**。**只有一个包**：m2 是建在 m1 之上的增量版本，手动分组、渠道优先级、单对话思考加在 m1 的完整能力之上，所以**直接覆盖安装 `rikkahub-3.1.1-m2.apk` 即可**，不需要先卸后装，也没有「先装哪个包」的问题。m1、r21 的 Release / tag / 资产原样保留，回退时按旧 tag 取包。

本轮新增三项，都可以不看不用：**手动对话归组**（会话抽屉长按 → 多选 → 归组，组内仍是独立会话，**不是把消息混在一起**）· **同模型多渠道优先级与故障切换**（设置 → 提供商，默认关闭，显式白名单严格按顺序调用，同协议族内切换，已出正文/思考/工具草稿后不重发）· **单对话思考强度**（只作用当前对话，新对话对支持推理的模型默认 MAX，旧选择保留）。

m1 审查指出的两项 P1（MCP 坏账本 fail-closed 与原子持久化、自动化存储失败阻断 dispatch）**本轮正在修**，尚未完成构建与窄验证，因此本文不把它们写成已修复。本轮也没有新 APK：正式 R8 构建、验签与升级验证稍后补记。
