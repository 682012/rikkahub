# RikkaHub · 个人增强分支（简体中文）

本仓库是基于官方 **3.1.1 / `ad2c4430`** 的非官方个人分支，当前维护版本 **`3.1.1-fork.38 / 3000042`**，分支 `fork/3.1.1`。

为避免多份介绍互相过期，中文主说明统一维护在 [仓库首页 README](README.md)。

- [与官方的完整差异、新增工作流、功能增强与限制](fork/FEATURES.md)
- [当前版本与历史更新](fork/CHANGES.md)
- [构建、签名与回退](fork/README.md)
- [fork.38 更新与验收](fork/RELEASE-fork38.md)

按用途分为 5 组新增工作流（子代理、后台任务、HTTP 执行、自动压缩、ZIP 工作区迁移）及 2 项主要增强（重试策略、单会话用量）。SSH、MCP、Skills、历史检索与全局统计继承官方，不计为分支原创。

此仓库仅记录个人源码修改，不提供面向公众的 APK 分发或技术支持。官方渠道提供的是官方版，包名、签名与本分支不同。上游项目介绍、官方渠道、赞助及贡献者信息见 [rikkahub/rikkahub](https://github.com/rikkahub/rikkahub)。
