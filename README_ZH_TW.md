# RikkaHub · 個人增強分支（繁體中文）

專案功能與安裝說明統一維護於 [README](README.md)，避免多份說明版本不同步。

目前版本 **Meridian `3.1.1-m2` / `3000071`**。**只有一個包**：m2 是建在 m1 之上的增量版本，手動分組、頻道優先順序、單一對話思考加在 m1 的完整能力之上，所以**直接覆蓋安裝 `rikkahub-3.1.1-m2.apk` 即可**，不需要先卸載再安裝，也沒有「先裝哪個包」的問題。m1、r21 的 Release / tag / 資產原樣保留，回復舊版時依舊 tag 取包。

本輪新增三項，都可以不用：**手動對話歸組**（會話抽屜長按 → 多選 → 歸組，組內仍是獨立會話，**不是把訊息混在一起**）· **同模型多頻道優先順序與故障切換**（設定 → 提供商，預設關閉，明確白名單嚴格依序呼叫，同協定族內切換，已輸出正文/思考/工具草稿後不重發）· **單一對話思考強度**（只作用目前對話，新對話對支援推理的模型預設 MAX，舊選擇保留）。

m1 審查指出的兩項 P1（MCP 壞帳本 fail-closed 與原子持久化、自動化儲存失敗阻斷 dispatch）**本輪正在修**，尚未完成建置與窄幅驗證，因此本文不把它們寫成已修復。本輪也沒有新 APK：正式 R8 建置、驗簽與升級驗證稍後補記。
