# RikkaHub · 個人增強分支

本倉庫是基於官方 **3.1.1 / `ad2c4430`** 的非官方個人分支，目前維護版本為 **`3.1.1-fork.38 / 3000042`**，分支 `fork/3.1.1`。

完整介紹集中維護於 [倉庫首頁](README.md)，避免各語言頁面的功能和版本資訊互相過期。

- [與官方的差異、新增工作流、功能增強與限制](fork/FEATURES.md)
- [版本紀錄](fork/CHANGES.md)
- [建置與維護](fork/README.md)
- [審查與驗證範圍](fork/RELEASE-fork38.md)

按用途分為 5 組新增工作流（子代理、背景任務、HTTP 執行、自動壓縮、ZIP 工作區遷移）及 2 項主要增強（重試策略、單一對話用量）。SSH、MCP、Skills、歷史檢索與全域統計繼承官方，不計為分支原創。

本倉庫記錄個人原始碼修改，並在 [GitHub Releases](https://github.com/682012/rikkahub/releases/tag/v3.1.1-fork.38) 提供已驗 APK 與校驗檔案，方便重複下載；不提供官方或面向終端使用者的技術支援。官方下載管道提供的是官方版本，不能當成本分支安裝包。上游介紹、贊助與貢獻者資訊請參閱 [rikkahub/rikkahub](https://github.com/rikkahub/rikkahub)。
